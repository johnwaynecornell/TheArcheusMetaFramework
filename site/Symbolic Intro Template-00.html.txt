        <p><strong>Symbolic Document Preface Template</strong></p>
        <hr>
        <h4>☉ Purpose:</h4>
        <p>To provide a reusable, human-facing HTML introduction block to be displayed above symbolic documents in web contexts. This introduction orients readers toward the nature, usage, and timing of the symbolic document that follows. It is meant to be embedded before <code>&lt;!--&nbsp;#CONTENT#&nbsp;--&gt;</code> in symbolic <code>.html</code> files.</p>
        <hr>
        <h4>⊚ Structure:</h4>
        <p>The introduction is written in <strong>HTML</strong> and is presented in a code block, not symbolic syntax or comment form. It includes:</p>
        <ul>
            <li>
                <p>Document identity and tone-setting</p>
                </li>
            <li>
                <p>Description of its symbolic layer (SLF, ARF, MCF, etc.)</p>
                </li>
            <li>
                <p>Use cases for the document</p>
                </li>
            <li>
                <p>Reflection on how to read the symbolic form (as structure, not instruction)</p>
                </li>
            <li>
                <p>Guidance on onboarding timing</p>
                </li>
            </ul>
        <hr>
        <h4>⊡ Recommended Timing for Onboarding:</h4>
        <p>This preface should be delivered when the practitioner:</p>
        <ul>
            <li>
                <p>Has already encountered the foundational SLF, ARF, and MCF pages</p>
                </li>
            <li>
                <p>Is entering the first symbolic document of a new category (e.g., their first Reflex Node, Execution Schema, or Pattern Library)</p>
                </li>
            <li>
                <p>Would benefit from a bridge between narrative understanding and symbolic form</p>
                </li>
            </ul>
        <p>It may be omitted if the practitioner is already fluent with symbolic interpretation.</p>
